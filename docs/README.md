Execuções locais geram arquivos em `outputs/`, na raiz do repositório, fora do Git. `docs/output/` guarda somente evidências selecionadas para revisão. Os JSONs históricos mantêm seus bytes e caminhos registrados na época; não foram reescritos para ajustar a organização da documentação.
